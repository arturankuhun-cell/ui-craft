ui-craft — воркфлоу для агентов, которые пишут UI: от чтения существующих токенов до проверки результата. Пять фаз (read the room → direction → architecture → build → verify → critique), справочники по типографике, цвету, раскладке, motion, a11y и React-перфомансу, плюс три скрипта без зависимостей.
